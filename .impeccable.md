# Impeccable — design context

Scope: the only design surface in this repo is `market-history/offer/` — the four
house-hunt web tools (`index.html` landing, `analyser.html`, `market.html`, `map.html`,
`sold.html`), deployed to GitHub Pages.

## Design Context

### Users
**Two people: the owner and his partner**, deciding on a house together — often on a
**phone**, sometimes in a car (the map page is explicitly a passenger-seat tool). The
partner did **not** build this, so nothing may rely on inside knowledge: every label has to
be understandable cold, on first read. The job: decide whether an asking price is fair, and
which towns are worth looking in, on a six-figure decision.

### Brand Personality
**Warm, grounded, honest.** Steady and reassuring rather than clinical — this is a big,
nervous decision and the interface should feel like a calm, well-informed friend, not a
dashboard. Voice is plain and direct; it never oversells what it knows.

The project's defining ethos (already lived in the code): **say how much you know and how
old it is.** Caveats ride *with* the number, never in a footnote. A pretty lie you'd make a
six-figure decision on is the worst possible outcome.

### Aesthetic Direction
**Editorial paper-and-ink**, light-only. An established token set is already shared across
all pages and is the house style — keep it:
- `--paper:#f7f4ee` `--paper-2:#f1ece3` `--rule:#ddd5c7` `--rule-2:#c8bda9`
- `--ink:#1f1c18` `--ink-2:#544d43` `--ink-3:#8a8072` `--flag:#a8631c` (accent, used sparingly)
- serif display: Iowan Old Style / Hoefler Text / Baskerville / Palatino
- sans body: Avenir Next / Seravek / Optima / Gill Sans

**Anti-references (explicit):** generic SaaS landing pages (hero + three identical icon
cards), dark-neon / AI-startup aesthetics (glow, purple-blue gradients), and corporate BI
dashboards (KPI tiles, widget chrome). Light mode only — no dark theme.

**Typography note:** avoid `-webkit-font-smoothing: antialiased`. It thins type on macOS and
reads as blurry/washed against the warm paper background; default (subpixel) rendering is
crisper and warmer here.

### Design Principles
1. **Understandable cold.** A person who didn't build it knows what every page is for in two
   seconds. Plain words beat clever ones — "Is this price fair?" over "what an ask is worth".
2. **The number carries its caveat.** Freshness and uncertainty are shown next to the value,
   never hidden. Colour must not launder an estimate into a fact.
3. **Fast scan over full explanation.** Especially the landing page: it's a signpost, not
   documentation. One short line per destination; cut every sentence in half.
4. **Warm, not clinical.** Generous space, serif headlines, warm neutrals. No cards-for-the-
   sake-of-cards, no icon rows, no widget chrome.
5. **Phone-first.** Big tap targets, readable at arm's length, legible in sunlight; nothing
   critical hidden on small screens.
